# picross_multiopt

This project is a solver for Picross (also known as Nonograms or Griddlers) puzzles, implemented in C++. It uses a multi-objective evolutionary algorithm (NSGA-II) to find solutions.

このプロジェクトは、C++で実装されたピクロス（お絵かきロジック）のソルバーです。多目的進化的アルゴリズム（NSGA-II）を用いて解を探索します。

## Description

The goal is to fill a grid with black and white cells according to number hints given for each row and column. The solver treats this as a multi-objective optimization problem with two objectives:

1.  Minimize the number of errors in the rows. (行の誤り数を最小化)
2.  Minimize the number of errors in the columns. (列の誤り数を最小化)

The puzzles to be solved are defined in `Question.h`.

## How to Build and Run (C++)

### Compilation

You can compile the C++ code using g++. Since all necessary `.cpp` files are included by `Fix.cpp`, the command is straightforward.

```bash
g++ Fix.cpp -o Fix -std=c++11
```

### Execution

After compilation, an executable file named `Fix` will be created. Run it from the terminal:

```bash
./Fix
```

The program will run the optimization algorithm and save the results (Pareto front data) as CSV files in the `results/` directory.

## How to Visualize Results (Python)

The `pareto.py` script is provided to visualize the Pareto fronts generated by the C++ solver.

### Prerequisites

You need Python 3 and the following libraries:

*   pandas
*   matplotlib

You can install them using pip:

```bash
pip install pandas matplotlib
```

### Usage

Run the script from the terminal:

```bash
python pareto.py
```

The script will read the CSV files from `results/` and save the generated plots as PNG images in the `results_fig/` directory. You can configure which simulation results to plot by editing the variables at the top of `pareto.py`.
