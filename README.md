# picross_multiopt

本プロジェクトは、ピクロス（お絵かきロジック／Nonograms／Griddlers）を解くための **C++製ソルバー** です。  
**多目的進化的アルゴリズム（NSGA-II）** を用いて解探索を行います。

## 概要（Description）

ピクロスは、各行・各列に与えられた数値ヒントに従って、マスを黒・白に塗り分けるパズルです。  
本ソルバーでは、この問題を **多目的最適化問題** として定式化し、以下の2つの目的関数を同時に最小化します。

1. 行方向の違反数を最小化  
2. 列方向の違反数を最小化  

解く対象となるピクロス問題（ヒント情報）は `Question.h` に定義されています。

## ビルド方法と実行方法（C++）

### コンパイル

C++コードは `g++` を用いてコンパイルできます。  
必要な `.cpp` ファイルはすべて `Fix.cpp` からインクルードされているため、以下のコマンドでコンパイル可能です。

```bash
g++ Fix.cpp -o Fix -std=c++11
```

### 実行

コンパイル後、`Fix` という実行ファイルが生成されます。  
以下のコマンドでプログラムを実行してください。

```bash
./Fix
```

プログラムは最適化アルゴリズムを実行し、  
**パレートフロント（評価結果）をCSVファイルとして `results/` ディレクトリに保存**します。

## 結果の可視化方法（Python）

C++ソルバーによって生成されたパレートフロントを可視化するために、  
`pareto.py` という Python スクリプトを用意しています。

### 必要環境

* Python 3
* 以下のライブラリ
  * pandas
  * matplotlib

インストールは以下のコマンドで行えます。

```bash
pip install pandas matplotlib
```

### 使用方法

ターミナルから以下を実行してください。

```bash
python pareto.py
```

`results/` ディレクトリ内のCSVファイルを読み込み、  
生成されたグラフを `results_fig/` ディレクトリにPNG形式で保存します。

どのシミュレーション結果を描画するかは、`pareto.py` 冒頭の変数を編集することで調整できます。

## プロジェクト構成

```
.
├── Fix.cpp             # C++アプリケーションのエントリポイント
├── Optimization.cpp    # 最適化アルゴリズムの実装
├── Optimization.h      # Optimization クラスのヘッダ
├── Parameters.cpp      # パラメータ設定の実装
├── Parameters.h        # パラメータ設定のヘッダ
├── Question.h          # ピクロス問題（ヒント）の定義
├── selection.cpp       # 進化的アルゴリズムの選択処理
├── selection.h         # 選択処理のヘッダ
├── pareto.py           # パレートフロント可視化用Pythonスクリプト
├── results/            # CSV形式の出力結果保存用ディレクトリ
└── results_fig/        # 可視化結果（画像）の保存用ディレクトリ
```
